# ecuacion-tools reference

This is the reference page for ecuacion-tools (`ecuacion-tool-xxx` modules).
It covers how to use the batch and API tools for server operations.

## What is ecuacion-tools?

ecuacion-tools is a set of tools designed to automate routine tasks in application operations and maintenance.
Each tool is provided as a standalone JAR or WAR — no integration into existing systems is required.

## Modules

| Module Name | Purpose |
| --- | --- |
| `ecuacion-tool-housekeep-files` | Routine file and directory management (copy, move, delete, compress, SFTP transfer, etc.) |
| `ecuacion-tool-housekeep-db` | Periodic database record deletion (soft delete / hard delete) |
| `ecuacion-tool-command-api` | Execute shell scripts on the server via Web API |

See each page in the navigation for details.
