## 1. Download the WAR File

Download the latest `ecuacion-tool-command-api-x.x.x.war` from
[GitHub Releases](https://github.com/ecuacion-jp/ecuacion-tools/releases).

Once downloaded, continue to [Quickstart](page?id=command-api/quickstart&lang=en). For details on how to start it — standalone or deployed to an existing Tomcat — see [Launch Patterns](page?id=command-api/launch-patterns&lang=en).

## System Requirements

- JDK 21 or above
- Linux, macOS, or Windows
