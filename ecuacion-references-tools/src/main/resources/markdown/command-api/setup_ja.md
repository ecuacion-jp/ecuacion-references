## 1. WAR ファイルのダウンロード

[GitHub Releases](https://github.com/ecuacion-jp/ecuacion-tools/releases) から最新の `ecuacion-tool-command-api-x.x.x.war` をダウンロードします。

ダウンロードが完了したら、[クイックスタート](page?id=command-api/quickstart&lang=ja)に進んでください。単独起動・既存Tomcatへのデプロイなど起動方法の詳細は[起動方法](page?id=command-api/launch-patterns&lang=ja)を参照してください。

## システム要件

- JDK 21 以上
- Linux、macOS、または Windows
