タスク設定シートの「処理パターン」列に指定する値と、各処理パターンの詳細を説明します。

処理パターンは大きく **ローカル操作** と **SFTP 操作** の 2 種類に分かれます。

---

## ローカル操作

ローカルファイルシステム上でのファイル・ディレクトリ操作です。

### CREATE\_DIR（101）— ディレクトリ作成

指定したパスにディレクトリを新規作成します。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 禁止（空白） |
| 先パス関連（4項目） | 必須 |
| 先パスがディレクトリ | `true` |

---

### CREATE\_FILE（102）— ファイル作成

指定したパスに空のファイルを新規作成します。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 禁止（空白） |
| 先パス関連（4項目） | 必須 |
| 先パスがディレクトリ | `false` |

---

### MOVE（111）— 移動

ファイルまたはディレクトリを別の場所に移動します。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 必須 |
| 先パス関連（4項目） | 必須 |

---

### COPY（121）— コピー

ファイルまたはディレクトリを別の場所にコピーします。元ファイルは残ります。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 必須 |
| 先パス関連（4項目） | 必須 |

---

### DELETE（131）— 削除

ファイルまたはディレクトリを削除します。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 必須 |
| 先パス関連（4項目） | 禁止（空白） |

---

### ZIP\_DELETE\_ORIG（141）— ZIP 圧縮（元ファイル削除）

ファイルを ZIP に圧縮し、元ファイルを削除します。
先パスを省略すると、元ファイルと同じ場所に `.zip` 拡張子で作成されます。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 必須 |
| 先パス関連（4項目） | 任意 |

---

### ZIP\_REMAIN\_ORIG（142）— ZIP 圧縮（元ファイル残す）

ファイルを ZIP に圧縮し、元ファイルはそのまま残します。
先パスを省略すると、元ファイルと同じ場所に `.zip` 拡張子で作成されます。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 必須 |
| 先パス関連（4項目） | 任意 |

---

### ZIP 圧縮の実装について

`ZIP_DELETE_ORIG` / `ZIP_REMAIN_ORIG` の ZIP 圧縮は、`java.util.zip` ではなく OS の `zip` コマンドを使用して実施しています。
`java.util.zip` はシンボリックリンクをそのまま zip 化できないため、git リポジトリや Docker データのように、シンボリックリンクを多く含むディレクトリを圧縮する際に不都合があったためです。

---

### UNZIP\_DELETE\_ORIG（151）— ZIP 解凍（元ファイル削除）

ZIP ファイルを解凍し、元の ZIP ファイルを削除します。
先パスを省略すると、ZIP ファイルと同じディレクトリに解凍されます。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 必須 |
| 先パス関連（4項目） | 任意 |

---

### UNZIP\_REMAIN\_ORIG（152）— ZIP 解凍（元ファイル残す）

ZIP ファイルを解凍し、元の ZIP ファイルはそのまま残します。
先パスを省略すると、ZIP ファイルと同じディレクトリに解凍されます。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 禁止（空白） |
| 元パス関連（4項目） | 必須 |
| 先パス関連（4項目） | 任意 |

---

## SFTP 操作

SFTP プロトコルを使用してリモートサーバとファイルをやり取りする処理パターンです。
すべての SFTP タスクで「接続先サーバ」が必須となります。

### SFTP\_CREATE\_DIR（201）— SFTPサーバ上にディレクトリ作成

リモートサーバ上に指定したパスのディレクトリを作成します。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 必須 |
| 元パス関連（4項目） | 禁止（空白） |
| 先パス関連（4項目） | 必須（先パスはリモートサーバ上のパス） |

---

### SFTP\_CREATE\_FILE（202）— SFTPサーバ上にファイル作成

リモートサーバ上に指定したパスの空ファイルを作成します。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 必須 |
| 元パス関連（4項目） | 禁止（空白） |
| 先パス関連（4項目） | 必須（先パスはリモートサーバ上のパス） |

---

### SFTP\_MOVE\_FROM\_SERVER（211）— SFTPサーバからローカルに移動

リモートサーバからファイルをローカルに移動します（リモートのファイルは削除されます）。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 必須 |
| 元パス関連（4項目） | 必須（元パスはリモートサーバ上のパス） |
| 先パス関連（4項目） | 必須（先パスはローカルのパス） |

---

### SFTP\_MOVE\_TO\_SERVER（212）— ローカルからSFTPサーバに移動

ローカルのファイルをリモートサーバに移動します（ローカルのファイルは削除されます）。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 必須 |
| 元パス関連（4項目） | 必須（元パスはローカルのパス） |
| 先パス関連（4項目） | 必須（先パスはリモートサーバ上のパス） |

---

### SFTP\_COPY\_FROM\_SERVER（221）— SFTPサーバからローカルにコピー

リモートサーバからファイルをローカルにコピーします（リモートのファイルは残ります）。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 必須 |
| 元パス関連（4項目） | 必須（元パスはリモートサーバ上のパス） |
| 先パス関連（4項目） | 必須（先パスはローカルのパス） |

---

### SFTP\_COPY\_TO\_SERVER（222）— ローカルからSFTPサーバにコピー

ローカルのファイルをリモートサーバにコピーします（ローカルのファイルは残ります）。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 必須 |
| 元パス関連（4項目） | 必須（元パスはローカルのパス） |
| 先パス関連（4項目） | 必須（先パスはリモートサーバ上のパス） |

---

### SFTP\_DELETE\_FROM\_SERVER（231）— SFTPサーバからファイルを削除

リモートサーバ上のファイルを削除します。

| 項目 | 入力 |
| --- | --- |
| 接続先サーバ | 必須 |
| 元パス関連（4項目） | 必須（元パスはリモートサーバ上のパス） |
| 先パス関連（4項目） | 禁止（空白） |
