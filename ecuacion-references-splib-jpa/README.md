# ecuacion-references-splib-jpa

## What is it?

`ecuacion-references-splib-jpa` is the hands-on tutorial web application for the JPA (DB-backed)
features of the `ecuacion-splib` web framework — optimistic locking and multi-table updates.
It is a working Spring Boot app connected to a PostgreSQL database, split out from
`ecuacion-references-splib-web` (which itself does not connect to a database).
