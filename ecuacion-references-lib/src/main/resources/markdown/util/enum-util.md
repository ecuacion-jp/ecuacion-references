`EnumUtil` (`jp.ecuacion.lib.core.util.EnumUtil`) is a utility class for the enum format used in ecuacion library modules.

---

## Enum Format in ecuacion Modules

ecuacion modules use a standard format where enums have the following 2 properties:

- **`code`**: A fixed code value used for database storage, HTML dropdown identification, etc.
- **Display name (displayName)**: A name for display on screen, retrieved from `enum_names.properties` via `PropertiesFileUtil.getEnumName(...)`

Enums generated by the code generator also follow this format.

```java
public enum StatusEnum {
    ACTIVE("1"), INACTIVE("0");

    private final String code;

    StatusEnum(String code) { this.code = code; }

    public String getCode() { return code; }

    public String getDisplayName(Locale locale) {
        return PropertiesFileUtil.getEnumName(locale, "StatusEnum." + name());
    }
}
```

---

## Getting an Enum Value from a Code

```java
// Get StatusEnum.ACTIVE corresponding to code "1"
StatusEnum status = EnumUtil.getEnumFromCode(StatusEnum.class, "1");

// Check if a code exists
boolean exists = EnumUtil.hasEnumFromCode(StatusEnum.class, "99"); // false
```

If the code does not exist, `getEnumFromCode` throws a `RuntimeException`.

## List for HTML Select Elements

Returns a list of code and display name pairs (`String[]`). Can be passed directly to Thymeleaf select tags and similar.

```java
// Returns a list like [["1", "Active"], ["0", "Inactive"]]
List<String[]> items = EnumUtil.getListForHtmlSelect(
    StatusEnum.class, Locale.ENGLISH, null);
```

### Filtering Options

Elements can be filtered using an option string.

| Option | Description | Example |
| --- | --- | --- |
| `including=V1\|V2` | Include only elements with the specified names | `including=ACTIVE\|PENDING` |
| `excluding=V1\|V2` | Exclude elements with the specified names | `excluding=DELETED` |
| `firstCharOfCodeEqualTo=X\|Y` | Only elements where the first character of code matches | `firstCharOfCodeEqualTo=1\|2` |
| `firstCharOfCodeLessThanOrEqualTo=X` | Only elements where the first character of code is X or less | `firstCharOfCodeLessThanOrEqualTo=3` |
| `firstCharOfCodeGreaterThanOrEqualTo=X` | Only elements where the first character of code is X or greater | `firstCharOfCodeGreaterThanOrEqualTo=2` |

Only one option can be specified at a time. Specifying multiple options results in an error.

```java
// Only ACTIVE
EnumUtil.getListForHtmlSelect(StatusEnum.class, Locale.ENGLISH, "including=ACTIVE");

// Exclude DELETED
EnumUtil.getListForHtmlSelect(StatusEnum.class, Locale.ENGLISH, "excluding=DELETED");
```

## Getting EnumClassInfo / EnumValueInfo

Retrieves information about an enum class (list of values, codes, display names) in bulk.

```java
EnumUtil.EnumClassInfo<StatusEnum> info =
    EnumUtil.getEnumInfo(StatusEnum.class, Locale.ENGLISH);

for (EnumUtil.EnumValueInfo<StatusEnum> valueInfo : info.getValueList()) {
    String name        = valueInfo.getName();     // "ACTIVE"
    String code        = valueInfo.getCode();     // "1"
    String label       = valueInfo.getLabel();    // "Active"
    StatusEnum instance = valueInfo.getInstance(); // StatusEnum.ACTIVE
}
```

When no locale is specified, `Locale.ROOT` is used.

```java
EnumUtil.EnumClassInfo<StatusEnum> info = EnumUtil.getEnumInfo(StatusEnum.class);
```
