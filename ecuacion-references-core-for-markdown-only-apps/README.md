# ecuacion-references-core-for-markdown-only-apps

## What is it?

`ecuacion-references-core-for-markdown-only-apps` provides base classes and shared resources
(config, exception handling, common templates) used internally by the Markdown-article-style
tutorial apps in this repository (`ecuacion-references-lib`, `ecuacion-references-splib`,
`ecuacion-references-utils`, `ecuacion-references-tools`, `ecuacion-references-tool-code-generator`).
It is a plain JAR module, not a runnable application.
