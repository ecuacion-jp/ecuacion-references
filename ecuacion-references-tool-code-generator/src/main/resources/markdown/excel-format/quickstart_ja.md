このページでは、新規プロジェクトでDB項目定義書（Excel）を用意する際の最低限の設定を説明します。
この内容は `code-generator-cli` と `code-generator-web` の両方に共通です。

## 各種設定

Excel ファイルを開き、**「各種設定」シート**に移動します。「システム共通」分類の 6〜11行目は全項目が入力必須で、
空欄のまま読み込むとエラーになります。

このうち新規プロジェクトで必ず値を変更する必要があるのは以下の 2 項目です。

| 行 | 項目 | 説明 | 例 |
| --- | --- | --- | --- |
| 7 | システム名 | プロジェクト識別名。生成ソースの親フォルダ名になる | `my-project` |
| 8 | packageの共通部分 | 生成コードの Java パッケージ共通部分 | `jp.example.myapp` |

この分類の残りの必須項目（6, 9〜11行目。テンプレートのバージョン・frameworkの種類・文字コード・デフォルト言語）は、
テンプレートに妥当な初期値が入っているため通常はそのままで構いません。値を削除しないよう注意してください。

これとは別に、「楽観的排他制御」分類のカラム名も必須項目です。テンプレートには `VERSION` が初期値として入力済みなので、
既存スキーマ上の他の用途と名前が衝突しない限りはそのままで構いません（このページでもこの初期値をそのまま使います）。

## dataType定義・DB項目定義（こちらも必須）

「各種設定」シートだけ埋めても、コードは生成されません。**「DB項目定義」シート**に最低1テーブルが必要で、
かつどのテーブルにもサロゲートキー用のカラムと、上で設定した楽観的排他制御用のカラム名に一致するカラムが必要です。
このセクションでは、この2条件を満たす最小限のテーブルを作成します。

### 1. DataTypeを3つ追加する

ブランクテンプレートの**「dataType定義」シート**は空の状態で配布されているため、単純な数値型であっても、
使う前にまず行を追加する必要があります。以下の3行を追加します。

| DataType名 | 型 | 長さ最大 | データパターン |
| --- | --- | --- | --- |
| `DT_SERIAL` | `LONG` | | |
| `DT_DB_UPD_VER` | `LONG` | | |
| `DT_NAME` | `STRING` | `100` | `All Characters` |

### 2. 3項目からなるテーブルを追加する

**「DB項目定義」シート**に以下の行を追加します。

| テーブル名 | カラム名 | dataType | Surrogate key | 自動採番 |
| --- | --- | --- | --- | --- |
| `USER` | `ID` | `DT_SERIAL` | ○ | ○ |
| `USER` | `NAME` | `DT_NAME` | | |
| `USER` | `VERSION` | `DT_DB_UPD_VER` | | |

- `ID` はサロゲートキーです（すべてのテーブルにちょうど1つ必要）。
- `NAME` は通常のカラムで、手順1で作成した `DT_NAME` を使います。
- `VERSION` は上の「各種設定」で設定した楽観的排他制御用のカラム名と一致しているため、特別なフラグなしで自動的に
  バージョンカラムとして扱われます。

これでコード生成は可能になります。複数テーブルを持つ実際のプロジェクトでは、`VERSION`（ソフトデリートや監査カラムを
使う場合はそれらも含め）を各テーブルに繰り返し定義するのではなく、**「DB共通項目定義」シート**に1回だけ定義するのが
一般的です。実際の使用例は [qiita-data-viewer](https://github.com/ecuacion-jp/qiita-data-viewer) を参照してください。

全項目の詳細は [各種設定シート](page?id=excel-format/general-settings&lang=ja)、
[dataType定義シート](page?id=excel-format/data-type-sheet&lang=ja)、
[DB項目定義シート](page?id=excel-format/db-definition-sheet&lang=ja) を参照してください。
