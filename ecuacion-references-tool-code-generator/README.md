# ecuacion-references-tool-code-generator

## What is it?

`ecuacion-references-tool-code-generator` is the tutorial and reference web application for
[`ecuacion-tool-code-generator`](https://github.com/ecuacion-jp/ecuacion-tool-code-generator). It is a
Markdown article site covering how to use the tool that auto-generates base module Java code
(JPA entities, repositories, business logic classes) for Spring Boot + JPA applications from a
DB Definition Book (Excel).
