### 対応していない要素

以下は出力しません。文書に含まれている場合はその要素を飛ばし（図形・グラフなどの描画要素は警告ログを出力）、残りの部分は出力します。

- 図形、テキストボックス、グラフ、SmartArt、数式
- 脚注・文末脚注、コメント
- 段組み、縦書き
- 浮動配置の画像に対する文字列の折り返し
- 小型英大文字、文字の拡大縮小（`w:w`）、文字位置の上げ下げ（`w:position`）、傍点
- EMF / WMF 形式の画像
- 旧形式の `.doc`：例外がスローされます（先に `.docx` で保存し直してください）

### Mac 版 Word を基準としたレイアウト

レイアウトは **Mac 版 Word** が書き出した PDF に合わせています。Windows 版 Word は一部のフォント
（例: 行グリッドありの 11pt 以上の游明朝）で行の高さが大きくなるため、Windows 版 Word が書き出した PDF とは
1 ページの行数や改ページ位置が異なることがあります。

Word と同じレイアウトにするには、文書で使われているフォントをサーバーにインストールし、
`builderForSystemFonts()` で使う必要があります。別のフォントでは文字幅が異なるため、改行・改ページの位置も変わります。

その他の既知の差異:

- 斜体は標準書体を傾けて描画します（Word はフォントに斜体書体があればそれを使います）。
- 両端揃えの英文で、Word は文字間もわずかに詰めますが、本ライブラリは単語間の空白だけを詰めます。
  改行位置は同じですが、行内の文字位置が 1pt 未満ずれることがあります。
- Word 2010 以前の互換モードの文書は Word との比較を行っていません（表の位置やセル内の行グリッドが異なる可能性があります）。

### 大きなファイルの扱い

Word ファイルはすべてメモリに読み込まれます。利用者がアップロードしたファイルを処理する場合は、
本ライブラリを呼び出す前にファイルサイズを確認することを推奨します。

```java
if (Files.size(wordPath) > 50 * 1024 * 1024) { // 例: 50 MB
    throw new IllegalArgumentException("ファイルサイズが上限を超えています");
}
WordToPdfUtil.generate(wordPath, outputPath, options);
```
