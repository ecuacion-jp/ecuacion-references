## 対応確認済みの機能

以下の機能は自動テストで確認しています。**（Word）** と付いた項目は、Mac 版 Word が書き出した PDF とのレイアウト比較も行っており、
すべての行が同じ文字列・同じ位置（誤差 1pt 以内）であることを確認しています。

### ページレイアウト

- **用紙サイズ・向き・余白・とじしろ**（セクションごと）**（Word）**
- **セクション**：次のページから／現在の位置から（連続）、それぞれ独自のページ設定・行グリッド・ヘッダー/フッター・ページ番号 **（Word）**
- **改ページ**：改ページ文字、「段落前で改ページ」、自動改ページ **（Word）**
- **次の段落と分離しない、段落を分割しない、改ページ時 1 行残して段落を区切らない** **（Word）**
- ページ先頭の段落前間隔は無視（セクションの最初のページを除く）**（Word）**

### 段落

- **配置**：左・中央・右・両端揃え・均等割り付け。両端揃えの最終行と、段落内改行で終わる行は伸ばさない **（Word）**
- **インデント**：左・右・字下げ・ぶら下げ（文字数単位の指定も含む）**（Word）**
- **段落間隔**：段落前・段落後（pt 単位・行単位）、「同じスタイルの場合は段落間にスペースを追加しない」**（Word）**
- **行間**：1 行・倍数・最小値・固定値、行グリッド（行送り）、グリッドに合わせない段落 **（Word）**
- **タブ**：既定のタブ位置、左揃え・中央揃え・右揃えタブ、リーダー（点線・ハイフン・下線）、ぶら下げ位置のタブ、位置指定タブ **（Word）**
- 段落の**罫線・網かけ** **（Word）**

### 改行位置

- 英単語の途中では改行しない（1 行に収まらない長い単語は分割する）**（Word）**
- **禁則処理**：行頭禁則・行末禁則、句読点のぶら下げ **（Word）**
- **約物の詰め**（`compressPunctuation`）：連続する全角約物、両端揃えの行への追い込み **（Word）**
- 和文と欧文・数字の間の**自動アキ**（およびその無効化）**（Word）**
- 両端揃えの英文で、Word と同じく単語間の空白を詰めて 1 語多く入れる **（Word）**
- 改行しないスペース・ハイフン

### 文字

- **サイズ、太字、斜体、下線（一重・二重）、取り消し線（一重・二重）、文字色、蛍光ペン、網かけ、上付き・下付き、文字間隔、すべて大文字** **（Word）**
- **文字種ごとのフォント**：欧文と和文で別のフォント **（Word）**、テーマのフォント
- **太字書体**：フォントファミリー自身に太字書体がある場合だけそれを使い、無い場合は Word と同じく標準書体を太らせ、字送りをサイズの 2% 広げる **（Word）**
- **スタイル**：文書の既定値、基準スタイルの連鎖、既定の段落スタイル、文字スタイル、直接の書式との優先順位 **（Word）**
- 隠し文字は出力しない

### 段落番号

- **多階層の番号**（例: `第1条` / `１` / `(1)`）、下位レベルの振り直し、開始番号とその上書き、段落スタイルに設定された番号 **（Word）**
- **番号書式**：算用数字・全角・囲み数字（丸・括弧）・ローマ数字・英字・漢数字（大字を含む）・アイウエオ・イロハ・行頭文字 **（Word）**
- 番号の後の区切り（タブ・空白・なし）と番号の配置 **（Word）**

### 表

- **列幅**：グリッドの幅、パーセント指定。長い単語より狭い列は広げる（固定レイアウトの表を除く）**（Word）**
- **表の配置・インデント**、表全体とセルごとのセル余白 **（Word）**
- **罫線**：表全体・セルごと、罫線なし・太線・二重線、罫線が取る幅 **（Word）**
- **セルの結合**：横・縦 **（Word）**
- **行の高さ**（最小値・固定値）、セル内の**縦位置** **（Word）**
- **ページをまたぐ行の分割**、分割しない行、**タイトル行の繰り返し** **（Word）**
- **表スタイル**：タイトル行・縞模様（行）**（Word）**
- **入れ子の表** **（Word）**

### ヘッダー・フッター・フィールド

- **ヘッダー・フッター**：既定・先頭ページ・偶数ページ、前のセクションからの継承、上余白より高いヘッダーによる本文の押し下げ **（Word）**
- **ページ番号**（`PAGE`・`NUMPAGES`・`SECTIONPAGES`）：ヘッダー・フッター・本文中。セクションの番号書式・開始番号、フィールドの書式スイッチ **（Word）**
- **目次と `PAGEREF`**：ページ番号を PDF のレイアウトから計算し直し、見出しへのリンクを張る **（Word）**
- 見出しのアウトラインレベルから PDF の**しおり（アウトライン）**を作成
- その他のフィールドは Word ファイルに保存された結果を出力

### 画像

- **行内の画像**（PNG・JPEG など）、表のセル内の画像、画像を含む行の高さ **（Word）**
- **浮動配置の画像**：ページ・余白・段落を基準とした位置（文字列の折り返しには対応しない）
- 同じ画像を複数回使っても PDF への埋め込みは 1 回

### その他

- **変更履歴**：挿入は出力、削除は出力しない
- **コンテンツコントロール**、スマートタグ、ハイパーリンク
- **パスワード付き Word ファイル**と**出力 PDF のパスワード保護**
- マクロ有効文書・テンプレート（`.docm`・`.dotx`・`.dotm`）：`.docx` と同様に変換（マクロは実行しない）
