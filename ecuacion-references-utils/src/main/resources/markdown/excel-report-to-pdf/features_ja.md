## 確認済み対応機能

以下の機能は自動テストによって動作が確認されています。分野ごとに分類しています。

### ページレイアウト

- **ページサイズ・向き**: 対応する用紙サイズ: A4, A5, Letter。縦向き・横向きともに対応。
- **余白（左・上）**: Excel で設定した左・上の余白値が PDF に正確に反映される。Normal（左=0.7in）、Wide（左=1.0in）、Narrow（左=0.25in）、および任意の値で確認済み。
- **印刷範囲**: 明示的に指定した印刷範囲内のセルのみが PDF に描画される。印刷範囲が未設定の場合は使用済みセル範囲が印刷される。
- **改ページ**: 手動の行区切りにより、指定した行でコンテンツが複数ページに分割される。手動の列区切りにより、指定した列でコンテンツが複数ページに分割される。
- **拡大縮小（明示的なパーセント指定）**: 明示的な拡大縮小率（例: 50%, 100%, 200%）が、PDF 上のセル形状（行の高さ・列の幅）およびフォントサイズに正確に適用される。
- **ページに合わせる（拡大縮小率の明示指定なし）**:
  - 印刷可能領域より幅または高さが大きいコンテンツは、1ページに収まるよう自動的に縮小される
  - もともと収まるコンテンツは縮小されず、自然なサイズのまま描画される
  - 列幅の制約・行高の制約の両方が考慮され、より厳しい方の制約で最終的な拡大縮小率が決まるため、両方向とも1ページに収まることが保証される
  - 拡大縮小率は行の高さ・列の幅・**フォントサイズ**に一律に適用され、Excel の cm 行列によるスケーリング挙動と一致する
- **印刷タイトル行**: Excel のページ設定で「タイトル行」（先頭で繰り返す行）が設定されている場合、それらの行が PDF の各ページ上部に描画される。タイトル行より前に存在する行（前置行）は、Excel の挙動と同様に、繰り返しタイトル行の上、1ページ目のみに描画される。
- **印刷タイトル列**: Excel のページ設定で「タイトル列」（左端で繰り返す列）が設定されている場合、それらの列が PDF の各ページ左端に描画される。印刷タイトル行と組み合わせ可能。両方とも各ページに描画される。

### ヘッダー・フッター

- Excel で設定したヘッダー/フッター余白領域内にヘッダー・フッターのテキストが描画される
- 対応する書式コード: `&L`/`&C`/`&R`（セクション揃え）、`&P`/`&P+n`/`&P-n`（ページ番号）、
  `&N`（総ページ数）、`&D`（日付）、`&T`（時刻）、`&A`（シート名）、`&F`（ファイル名）、
  `&Z`（ファイルパス）、`&B`（太字）、`&U`（下線）、`&E`（二重下線）、`&S`（取り消し線）、
  `&X`/`&Y`（上付き/下付き）、`&nn`（フォントサイズ）、`&"Font,Style"`（フォント）、
  `&KRRGGBB`（色）、`&&`（`&` のリテラル）
- `&I`（イタリック）は解析はされるが、埋め込みフォントにイタリック書体がないため効果はない
- **ヘッダー/フッター内の画像（`&G`）は非対応。** 画像はシートのセルに直接配置すること。

### セルの罫線

- 実線罫線: THIN, MEDIUM, THICK はそれぞれの線幅（0.5pt, 1.0pt, 1.5pt）で描画される
- 破線・点線罫線: DASHED, DOTTED, DASH_DOT, DASH_DOT_DOT, MEDIUM_DASHED,
  MEDIUM_DASH_DOT, MEDIUM_DASH_DOT_DOT, SLANTED_DASH_DOT はそれぞれ対応する破線パターンで描画される
- 罫線の色が PDF に反映される
- 四辺（上下左右）それぞれ独立して対応
- **斜め罫線**: ↘（左上から右下）・↗（左下から右上）の両方に対応し、破線スタイルも含む。
  両方同時に有効化できる
- DOUBLE 罫線スタイルは非対応

### セルのテキスト

- フォントサイズが PDF に正確に反映される
- **太字**に対応
- **イタリック**に対応（埋め込みフォントに真のイタリック書体がないため、シアー変換による疑似イタリックとして描画される）
- **取り消し線**に対応
- **上付き文字**・**下付き文字**に対応（70%サイズ、ベースライン調整の上で描画）
- 文字色が PDF に反映される
- **横方向の配置**: LEFT, CENTER, RIGHT に対応。GENERAL 配置では数値・日付は右揃え、
  文字列は左揃えとなり、Excel の既定動作と一致する
- **インデント**: セルのインデントレベルが適用され、LEFT 揃えのテキストは右へ、RIGHT 揃えのテキストは左へ、インデントレベルごとに概ね1文字分シフトする
- **縦方向の配置**: TOP, CENTER, BOTTOM に対応
- 数式セルは数式文字列ではなくキャッシュされた計算結果値を表示する。配置は結果の型に従う（数値→右揃え、文字列→左揃え、GENERAL 配置時）
- **折り返して全体を表示**（`wrapText`）に対応。長いテキストはセル内で複数行に折り返される
- **縮小して全体を表示**（`shrinkToFit`）に対応。1行のテキストがセル幅に収まるようフォントサイズが縮小される
- **縦書き**（回転角 = 255）に対応。文字が上から下へ積み重なり、セル内で水平方向に中央揃えされる
- セルの高さを超えるテキストはクリップされる: TOP 揃えでは下側の行が、BOTTOM または CENTER
  揃えでは上側の行が非表示になる
- フォントの行の高さがセルの高さをわずかに超える場合（例: ページに合わせる縮小後の詰まった行での太字大サイズフォント）でも正しく描画される。以前は浮動小数点のガード処理により、そのようなセルのテキストが全て非表示になることがあった

### セルの数値・日付書式

- 標準の数値書式が正しく描画される: 整数（`0`）、小数（`0.00`）、桁区切り（`#,##0`）、
  パーセント（`0%`, `0.0%`）、通貨（`¥#,##0`, `$#,##0.00`）、指数表記（`0.00E+00`）、
  負の数
- 日付書式: `yyyy/mm/dd`, `mm/dd/yyyy`, `dd/mm/yyyy`, `yyyy-mm-dd`, `yyyy年m月d日`、
  2桁年表記（`yy/mm/dd`）に対応
- ロケール依存の組み込み日付書式（例: Excel の書式ID 14）は、`PdfGenerateOptions.dateLocale()`
  のロケール（未設定時は `Locale.getDefault()`）を使用する `DateTimeFormatter.ofLocalizedDate`
  で描画される。これによりあらゆるロケールが自動的にカバーされる（例: 日本語→`2018/02/21`、
  米国→`2/21/18`、イタリア語→`21/02/18`）
- 月名の省略形・完全形（`mmm`, `mmmm`）は、書式文字列中の `[$-xxx]` コードで指定されたロケールで描画される（未指定時は英語）
- `aaa`/`aaaa` トークンによる日本語の曜日名（例: `月`, `月曜日`）、`ddd`/`dddd` トークンによる英語の曜日名（例: `Wed`, `Wednesday`）に対応
- 時刻のみの書式（`h:mm`, `h:mm:ss`, `h:mm AM/PM`）、日付と時刻を組み合わせた書式（例: `yyyy/mm/dd h:mm:ss`）に対応
- 数式セルは、セルの書式文字列に従ってフォーマットされたキャッシュ済み計算結果値を表示する
- **和暦**: 令和（`ggge"年"m"月"d"日"` 等）は 2019-05-01 以降の日付に対応。2019-05-01 より前の日付は PDF 生成時に `RuntimeException` をスローする。平成以前の元号は非対応
- `??` 配置を伴う会計style のゼロ表示部と引用リテラル（例: `"-"??`）は、値がゼロの数式セルに対して引用リテラル `"-"` として描画される。以前は `??` プレースホルダーが誤って数字の `0` として描画され、`"- 0"` になっていた
- **下線**（`U_SINGLE`, `U_SINGLE_ACCOUNTING`）・**二重下線**（`U_DOUBLE`,
  `U_DOUBLE_ACCOUNTING`）に対応。会計用のバリアントはセル全幅に、標準のバリアントはテキスト幅のみに線が引かれる
- **角度回転**（値 1〜254）は非対応。縦書き（回転角 = 255）のみ描画される
- GENERAL 配置の数値は、隣接セルが空かどうかに関わらず、セル境界内で正しく右揃えされる
- セル幅を超える文字列テキストはセル境界でクリップされる。Excel のように隣接する空セルへ視覚的にはみ出す挙動は再現されない

### セルの背景色

- 単色塗りつぶし（`SOLID_FOREGROUND`）は、テーマカラーへの tint 適用（明るく/暗く）を含め、正確な RGB 値で描画される
- 塗りつぶしなしのセルは白背景で描画される
- インデックスカラー（レガシーパレット）に対応
- テーマカラーに対応。tint 値（正=明るく、負=暗く）は `getRGBWithTint()` により正しく適用される
- **単色以外の塗りつぶしパターン**（例: `THIN_HORZ_BANDS`, `BRICKS` 等）は背景の塗りつぶしとして描画されない — `SOLID_FOREGROUND` のみ対応
- 背景の塗りつぶしはテキストより先に描画されるため、テキストは期待通り背景色の上に描画される

### 画像

- PNG・JPEG 画像に対応。透過 PNG 画像は PDF 描画時も透過が維持される
- 二点アンカー（行・列に合わせてリサイズ）・一点アンカー（左上セルを基準に固定配置）の両方に対応
- 1シート上の複数画像はすべて描画される
- 複数ページにまたがる画像は、それぞれ正しいページに描画される
- 画像の拡大率が正しく適用される
- 印刷範囲外の列・行にアンカーされた画像・オートシェイプは、Excel の印刷挙動と同様に
  PDF 出力から除外される

### 結合セル

- 水平方向・垂直方向・矩形の結合範囲すべてに対応
- 結合範囲の罫線は最外周セルのスタイルを使用する: 右罫線は最も右のセル、下罫線は最下行のセルのものが使われる
- 背景の塗りつぶしは結合範囲全体に適用される
- 結合範囲内のテキスト配置（水平・垂直）が尊重される

### Excel テーブルスタイル

- セル範囲が Excel テーブル（`挿入 > テーブル`）としてテーブルスタイル付きで定義されている場合、そのスタイルが PDF 出力に適用される
- ヘッダー行の塗りつぶし、行の縞模様（奇数/偶数行の交互スタイル）、最初/最後の列のハイライトが、いずれもテーブルスタイルから描画される
- テーブルスタイルの `wholeTable` 要素で定義された内部の水平罫線（行区切り線）・外周の罫線が描画される
- ヘッダー行のフォント色の上書き設定が適用される。ヘッダーの塗りつぶしが暗色で、
  明示的なフォント色が解決できない場合は、自動的に白文字が使用される
- 組み込みの Excel テーブルスタイル（例: `TableStyleMedium6`）・ワークブック内で定義されたカスタムテーブルスタイルのどちらにも対応

### 複数シート

- 1回の PDF 出力に複数シートを指定できる。各シートのページが順番に連結され、
  1つの PDF ドキュメントとして出力される
