尚、form毎に存在するinsert pointは、formの数だけ存在する。それを表現するために、form-content[-x]のように記載。
（multipleForms == falseならform-contentのみ使用可、
　multipleForms == trueでかつusesForm2 == trueなら、form-content-1, form-content-2が使用可、など）
尚、form毎に存在するparameterは、formの数だけ存在する。それを表現するために、formMethod[x]のように記載。
（multipleForms == falseならformMethodのみ使用可、
　multipleForms == trueでかつusesForm2 == trueなら、formMethod1, formMethod2が使用可、など）
