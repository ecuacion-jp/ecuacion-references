# ecuacion-references-splib-web-web

## What is it?

`ecuacion-references-splib-web-web` is the hands-on tutorial web application for the `ecuacion-splib`
web framework. Unlike the Markdown article sites, this module is a working Spring Boot app built with
the actual framework — you operate real screens (form input, search/list, error handling, and more)
to learn how the framework behaves. It depends on `ecuacion-references-splib-web-base` for its shared
entity / record / repository / business-logic classes.
