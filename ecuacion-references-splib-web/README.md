# ecuacion-references-splib-web

## What is it?

`ecuacion-references-splib-web` is the hands-on tutorial web application for the `ecuacion-splib`
web framework. Unlike the Markdown article sites, this module is a working Spring Boot app built with
the actual framework — you operate real screens (form input, search/list, error handling, and more)
to learn how the framework behaves. This app does not connect to a database; DB-backed (JPA) features
of the framework are not demonstrated here.
